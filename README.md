# 📊 台股 AI 波段監控與選股系統（操作與策略手冊）

本系統結合 **GitHub Actions 自動排程**、**LINE Flex Message 表格卡片推播** 與 **Streamlit 互動看盤網頁**，每日自動掃描台股上市櫃 1,800 檔標的並監控持股攻守狀態。

* **互動看盤網頁**：https://streamlit.app
* **每日自動推播時間**：每個交易日下午 **17:00（台灣時間）**

---

## 一、 雙系統核心架構與技術重點

| 模組 | 檔案名稱 | 核心功能與解決方案 |
| :--- | :--- | :--- |
| **LINE 自動推播機器人** | `scanner_bot.py` | 由 GitHub Actions 排程啟動，透過 Yahoo Finance 批次高速下載全市場日 K 線（解決美國主機遭證交所阻擋問題），結合 FinMind 三大法人買賣超，推播彩色表格卡片至 LINE。 |
| **互動看盤與試算網頁** | `app.py` | 部署於 Streamlit Cloud，提供雙分頁介面：**分頁一**即時試算持股損益與高賣停損（自動抓取繁體中文股名/ETF名稱）；**分頁二**自由調整 RSI 與黃金分割參數，並以 Altair 高對比虛線圖表顯示支撐壓力。 |

## 二、 量化策略邏輯與白話操作對照表

### 1. 低接買點篩選條件（同時滿足）
* **長線保護短線**：收盤價位於 **60日季線（`MA60`）** 之上。
* **高點拉回修正**：距離近 20 日波段高點已回檔超過 `3%`，且股價 > `15` 元、5 日均量 > `1,000` 張。
* **黃金分割支撐**：股價精準回測近 60 日波段高低點的 **`0.382`、`0.500` 或 `0.618`** 支撐位（容許誤差 `±1.5%`）。
* **🔥 雙支撐共振加權**：若該黃金分割位與 **60日季線** 價差在 `2.5%` 以內，自動標記 **`🔥雙支撐`**（LINE 顯示 **`🔥共振`**）並優先排在最前面。
* **指標與籌碼確認**：`14日 RSI < 48`（相對低檔），且 **近 5 日三大法人合計買超 > 0 張**。

### 2. 持股高賣、防守與大跌股白話操作建議

| 系統顯示的白話建議 | 背後觸發的技術條件 | 實戰操作意義 |
| :--- | :--- | :--- |
| **`⏳ 還在跌先觀望(別急著接)`** | `RSI < 30` 且今日 RSI 仍低於昨日 RSI | 雖進入超賣區但賣壓仍在宣洩，指標尚未止跌彎曲，避免接刀。 |
| **`🟢 止跌反彈訊號(可試單/目標5日線)`** | `RSI < 30` 且今日 RSI 大於昨日 RSI（勾頭向上） | 跌勢煞車出現轉折，適合輕倉試單搶短線反彈，第一目標先看 5 日均線。 |
| **`🔥 漲多過熱(建議分批高賣)`** | `14日 RSI >= 75` | 短線漲幅過大進入超買過熱區，隨時可能拉回，適合分批獲利了結。 |
| **`📐 碰黃金壓力位(適合高賣)`** | 股價逼近近 60 日波段反彈 **`0.618`** 壓力位（`±1.5%` 內）且已獲利 | 跌深反彈遇到前波套牢壓力區，適合逢高調節。 |
| **`🚀 達黃金延伸目標(建議高賣)`** | 股價突破前高並逼近黃金延伸 **`1.272`** 目標位 | 波段強勢延伸滿足區，適合分批停利鎖住波段獲利。 |
| **`📉 跌破5日線(先鎖住獲利)`** | 帳面獲利 `>= 3%` 但收盤跌破 5 日均線 | 啟動移動停利機制，防止已賺到的波段利潤大幅回吐。 |
| **`🚨 跌破季線/黃金0.786(建議停損)`** | 收盤跌破 **60日季線** 與 **黃金 `0.786`** 兩者較高者（或虧損達 `-7%`） | 雙重防守支撐失守，應嚴格執行紀律停損控制風險。 |

## 三、 日常維護與金鑰檢查清單

1. **如何修改每天 LINE 盯盤的持股清單？**
   * 打開 GitHub 的 **`scanner_bot.py`**，編輯第 15 行的 `MY_HOLDINGS` 字典即可：
     ```python
     MY_HOLDINGS = {
         "2891": {"name": "中信金", "cost": 71.4},
         "5876": {"name": "上海商銀", "cost": 50.9},
     }
     ```
2. **必要的環境變數（Secrets）清單**
   * **GitHub Actions Secrets**（`Settings` → `Secrets and variables` → `Actions`）：需包含 `FINMIND_TOKEN`、`LINE_TOKEN`、`LINE_USER_ID`。
   * **Streamlit Cloud Secrets**（`App settings` → `Secrets`）：需包含 `FINMIND_TOKEN = "你的Token"`。
