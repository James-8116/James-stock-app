# 📊 台股 AI 波段監控與選股系統（操作與策略手冊）

這是一套結合 **Python 量化篩選**、**GitHub Actions 雲端自動化排程**、**LINE Bot 即時推播** 與 **Streamlit 互動看盤儀表板** 的台股波段監控與持股防守系統。

🔗 **互動看盤儀表板**：[開啟 Streamlit 儀表板](https://streamlit.app)

---

## 🚀 系統核心特色

* **極速全市場掃描**：透過 FinMind API 動態取得近 7 日內有效交易之上市櫃（TWSE / TPEx）4 碼一般股票，自動剔除已下市標的，搭配 `yfinance` 多執行緒批次下載，全市場掃描僅需約 **10～25 秒**。
* **回測驗證三大實戰風控（LINE 與網頁同步）**：
  1. **季線斜率向上濾網**：要求今日季線大於 5 日前季線（`60MA > 60MA_5d_ago`），過濾高檔做頭或季線下彎的假支撐。
  2. **當日止跌確認**：須符合當日收紅 K（`Close > Open`）或 14 日 RSI 翻揚向上，不在暴跌當天盲目接刀。
  3. **6% 硬性風控上限**：自動剔除「結構防守線（季線或 0.786）距離現價超過 6.5%」的過熱飆股，並以 `-6%` 作為硬性停損保底，杜絕中小型股單筆重傷。
* **階梯式防守防線（大盤與個股統一基準）**：全面採用實戰化的 **費波那契三階支撐（0.500 合理回檔 / 0.618 深度回檔 / 0.786 極限防守線）**。
* **行動端與直覺看盤介面**：
  * 頂端標題正下方直接配置分頁按鈕，一鍵切換「持股階梯監控」與「全市場低接掃描」。
  * 大盤與個股各自擁有獨立的 `20日 / 60日 / 120日 / 240日` 計算週期按鈕，互不干擾。
  * 個股表格優先呈現現價、三階支撐、雙重防守線與白話建議（成本、損益、RSI 移至右側），且手機點擊代號輸入框自動彈出純數字鍵盤。
* **盤中靜音與盤後籌碼總結**：LINE Bot 於台灣時間 16:00 前執行「盤中即時預警」（無符合標的則靜音不洗版）；16:00 後執行「盤後完整總結」，固定推播大盤風向、精選標的與當日三大法人買賣超焦點。

## 📈 量化選股與進出場策略

### 1. 基礎濾網（流動性與價格保護）
* **市場範圍**：上市（`.TW`）與上櫃（`.TWO`）4 碼純數字標的（自動排除已下市股票）。
* **流動性門檻**：5 日均量（`Vol MA5`）須大於 **1,000 張**，避免流動性風險。
* **股價門檻**：收盤價須大於 **15 元**，過濾低價雞蛋水餃股。

### 2. 多頭順風模式（大盤站上 60MA 季線）
主打「強勢股回測支撐低接」策略：
* **趨勢與斜率**：個股站穩季線（`Close > 60MA`）且**季線斜率向上**，同時距離近 20 日高點已有 **3% 以上**之健康拉回。
* **費波那契回測支撐**：股價或當日最低價觸及近 60 日波段之 **0.382 / 0.500 / 0.618** 關鍵回檔位（容許誤差 ±1.5%）。
* **動能與止跌確認**：14 日 RSI 低於 **48**，且當日須收紅 K 或 RSI 勾頭向上。
* **停損與分批停利策略**：
  * **硬性風控停損**：取「季線（60MA）」、「波段 0.786 防線」與「進場價 -6%」三者最高價（若結構防守線距離現價 > 6.5% 則直接剔除）。
  * **分批停利建議**：到達第一目標（月線 20MA）建議先獲利了結一半，剩餘部位將停損上移至**進場成本價（保本）**，續抱上看第二目標（近 20 日前高）。

### 3. 空頭防守模式（大盤跌破 60MA 季線）
主打「極度超賣短線止跌反彈」策略：
* **進場訊號**：14 日 RSI 跌破 **28** 進入超賣區，且當日 RSI 較前一日翻揚向上（止跌勾頭）。
* **停損與停利設定**：
  * **防守停損**：當日最低價往下 **3%**（`Low × 0.97`）。
  * **停利目標**：第一目標為 5 日線（5MA），第二目標為月線（20MA）。

## ⏰ 雲端自動化排程（GitHub Actions）

透過 `.github/workflows/daily_scan.yml` 設定，每週一至週五自動於以下台灣時間執行（已啟用 `pip` 快取加速）：

| 執行時段（台灣時間） | UTC 時間 (`cron`) | 執行模式 | 推播行為說明 |
| :--- | :--- | :--- | :--- |
| **09:35** | `35 1 * * 1-5` | ⚡ 盤中即時預警 | 有符合高勝率條件標的才推播；無標的則靜音 |
| **11:05** | `5 3 * * 1-5` | ⚡ 盤中即時預警 | 有符合高勝率條件標的才推播；無標的則靜音 |
| **12:35** | `35 4 * * 1-5` | ⚡ 盤中即時預警 | 有符合高勝率條件標的才推播；無標的則靜音 |
| **16:30** | `30 8 * * 1-5` | 📊 盤後完整總結 | 固定發送大盤風向、精選標的與三大法人買賣超焦點 |

## ⚙️ 環境變數與 Secrets 設定

若需重新部署或移轉專案，請至 GitHub Repository 的 **Settings → Secrets and variables → Actions**（以及 Streamlit Cloud 的 **App settings → Secrets**）設定以下金鑰：

* `LINE_TOKEN`：LINE Messaging API 的 Channel Access Token
* `LINE_USER_ID`：接收推播通知的個人 User ID 或群組 Group ID
* `FINMIND_TOKEN`：FinMind API 金鑰（用於取得最新上市櫃清單與三大法人買賣超數據）
