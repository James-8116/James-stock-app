# 📊 台股 AI 波段監控與選股系統（操作與策略手冊）

這是一套結合 **Python 量化篩選**、**GitHub Actions 雲端自動化排程**、**LINE Bot 即時推播** 與 **Streamlit 互動看盤儀表板** 的台股波段監控系統。

🔗 **互動看盤儀表板**：[開啟 Streamlit 儀表板](https://streamlit.app)

---

## 🚀 系統核心特色

* **極速全市場掃描**：透過 FinMind API 動態取得近 7 日內有效交易之上市櫃（TWSE / TPEx）4 碼一般股票，自動剔除已下市標的，搭配 `yfinance` 多執行緒批次下載，全市場掃描僅需約 **10～25 秒**。
* **大盤多空風向自動切換**：即時追蹤台灣加權指數（`^TWII`）與季線（60MA）相對位置，自動切換「多頭順風」與「空頭防守」兩套選股邏輯。
* **盤中靜音防洗版機制**：台灣時間 16:00 前判定為「盤中即時預警」，若無符合嚴格條件之標的則靜音略過，不發送空白通知打擾。
* **盤後完整籌碼總結**：台灣時間 16:00 後判定為「盤後完整總結」，除精選個股與關鍵價位外，自動彙整當日三大法人買賣超焦點個股。

## 📈 量化選股與進出場策略

### 1. 基礎濾網（流動性與價格保護）
* **市場範圍**：上市（`.TW`）與上櫃（`.TWO`）4 碼純數字標的（自動排除已下市股票）。
* **流動性門檻**：5 日均量（`Vol MA5`）須大於 **1,000 張**，避免流動性風險。
* **股價門檻**：收盤價須大於 **15 元**，過濾低價雞蛋水餃股。

### 2. 多頭順風模式（大盤站上 60MA 季線）
主打「強勢股回測支撐低接」策略：
* **趨勢與乖離**：個股站穩季線（`Close > 60MA`），且距離近 20 日高點已有 **3% 以上**之健康拉回。
* **費波那契回測支撐**：股價或當日最低價觸及近 60 日波段之 **0.382 / 0.500 / 0.618** 關鍵回檔位（容許誤差 ±1.5%）。
* **指標冷卻**：14 日 RSI 低於 **48**（避免追高過熱）。
* **盤中加嚴濾網**：盤中執行時，股價須貼近支撐位（`<= 支撐價 × 1.005`），且同時具備 **🔥 均線共振**（費波那契支撐與季線誤差在 2.5% 內）或 **🪝 RSI 勾頭**（RSI < 30 且開始翻揚）。
* **停損與停利設定**：
  * **防守停損**：取「季線（60MA）」與「近 60 日波段 0.786 回檔位」兩者較高者。
  * **停利目標**：第一目標為月線（20MA），第二目標為近 20 日前高。

### 3. 空頭防守模式（大盤跌破 60MA 季線）
主打「極度超賣短線止跌反彈」策略：
* **進場訊號**：14 日 RSI 跌破 **28** 進入超賣區，且當日 RSI 較前一日翻揚向上（止跌勾頭）。
* **停損與停利設定**：
  * **防守停損**：當日最低價往下 **3%**（`Low × 0.97`）。
  * **停利目標**：第一目標為 5 日線（5MA），第二目標為月線（20MA）。

## ⏰ 雲端自動化排程（GitHub Actions）

透過 `.github/workflows/daily_scan.yml` 設定，每週一至週五自動於以下台灣時間執行（已啟用 `pip` 快取加速）：

| 執行時段（台灣時間） | UTC 時間 (`cron`) | 執行模式 | 推播行為說明 |
| :--- | :--- | :--- | :--- |
| **09:35** | `35 1 * * 1-5` | ⚡ 盤中即時預警 | 有符合高勝率條件標的才推播；無標的則靜音 |
| **11:05** | `5 3 * * 1-5` | ⚡ 盤中即時預警 | 有符合高勝率條件標的才推播；無標的則靜音 |
| **12:35** | `35 4 * * 1-5` | ⚡ 盤中即時預警 | 有符合高勝率條件標的才推播；無標的則靜音 |
| **16:30** | `30 8 * * 1-5` | 📊 盤後完整總結 | 固定發送大盤風向、精選標的與三大法人買賣超焦點 |

*(註：亦支援於 GitHub Actions 頁面透過 `workflow_dispatch` 隨時手動觸發測試。)*

## ⚙️ 環境變數與 Secrets 設定

若需重新部署或移轉專案，請至 GitHub Repository 的 **Settings → Secrets and variables → Actions** 設定以下三組金鑰：

* `LINE_TOKEN`：LINE Messaging API 的 Channel Access Token
* `LINE_USER_ID`：接收推播通知的個人 User ID 或群組 Group ID
* `FINMIND_TOKEN`：FinMind API 金鑰（用於取得最新上市櫃清單與三大法人買賣超數據）
